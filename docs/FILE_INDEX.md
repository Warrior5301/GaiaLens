# Complete file inventory

Paths are relative to `isro-vlm/`. Generated dependency/build caches, Git internals, local secrets and recovery archives are omitted. Consult the root README for the role of each directory and major entry point. Service source filenames retain their upstream naming.

Common service files: `main.py`/`app.py`/`api.py` expose HTTP handlers; `schemas.py` defines request/response models; `model_service.py` owns inference; `image_utils.py` handles image conversion; `config.py` holds settings; `modal_app.py` packages remote deployment; manifests specify that service's dependencies. `test_*.py` files validate their corresponding components or live APIs.
